# hiragana

Ứng dụng web học và luyện tập bảng chữ cái Hiragana (18 chữ cuối).

## 🚀 Tính năng
- Hiển thị ngẫu nhiên các ký tự Hiragana để kiểm tra phản xạ.
- Nhập Romaji và kiểm tra kết quả ngay lập tức.
- Nút hiển thị đáp án khi cần gợi ý.
- Thống kê tiến độ học tập.

## 💻 Cách chạy
Mở file `index.html` (hoặc `preview.html`) trực tiếp bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox, ...).
Hoặc kích hoạt GitHub Pages trong Settings repo để sử dụng online trực tiếp.
